# E-commerce Sales Dashboard | 2022

An interactive dashboard for exploring e-commerce sales, profit, products, categories, cities, and customer activity during 2022. It brings key metrics and visual summaries together to help users review business performance and identify trends.

> **Data note:** This project uses data for demonstration purposes. Replace this note with the correct description of your dataset, including its source and any privacy considerations.

## Project Objective

The objective of this project is to analyze 2022 e-commerce performance in one dashboard. It is designed to help users:

- Review headline sales, profit, quantity, and order figures.
- Compare product and category performance.
- Explore sales trends by month.
- Compare city-level profit and sales.
- Filter results by month, order status, and payment method.
- Present the findings in a clear, interactive format.

### Product-Wise Profit — Treemap

A **treemap** compares profit across products. Each rectangle represents a product, and the displayed value shows its profit. Larger rectangles indicate a larger share of the measure used to size the visual.

### Month-Wise Sales — Column Chart

A **clustered column chart** shows total sales for each month from January to December. It makes it easier to compare monthly values and see how sales change through the year.

### Category-Wise Sales — Doughnut Chart

A **doughnut chart** shows the share of sales attributed to each category: Electronics, Furniture, Clothing, and Home. The segments represent each category’s contribution to the displayed total.

### City-Wise Profit — Column Chart

A **column chart** compares total profit across Lahore, Rawalpindi, Karachi, Islamabad, and Faisalabad.

### City-Wise Total Profit & Sales — Stacked Column Chart

A **stacked column chart** compares profit and sales for each city. The legend distinguishes the two measures, allowing a side-by-side city comparison within a single visual.
